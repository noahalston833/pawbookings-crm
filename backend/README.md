# PawBookings CRM — Backend

Ruby on Rails 8 API. See the [repository root README](../README.md) for full setup instructions.

```
bin/setup          # install gems, prepare the database
bin/rails server    # start the API on :3000
bin/rspec           # run the test suite
bin/rubocop         # lint
bin/brakeman        # static security analysis
bin/bundler-audit   # dependency vulnerability scan
```
