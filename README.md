# PawBookings CRM

A multitenant CRM and booking platform for dog daycare, boarding, and
training businesses.

> Under active development. See `docs/` for architecture notes and
> `README.md` setup instructions as they are written (tracked via commit
> history / milestones).

## Stack

- **Backend:** Ruby on Rails 8 (API mode), PostgreSQL, Pundit, Solid Queue
- **Frontend:** React (JavaScript, no TypeScript), Vite, React Router,
  TanStack Query

## Layout

```
backend/   Rails API (app/, config/, db/, spec/)
frontend/  React SPA (src/)
docs/      Architecture and API documentation (added in a later milestone)
```
